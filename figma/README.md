## How to open the .fig file

**.fig files require Figma.** You cannot open them in a browser or standard image viewer.

### Option 1 — Figma (free account)
1. Go to [figma.com](https://figma.com) and sign in or create a free account.
2. On your home dashboard, click **Import** (or drag the `.fig` file directly onto the page).
3. The file will open as a local copy in your drafts.

### Option 2 — Figma Desktop App
1. Download the app from [figma.com/downloads](https://www.figma.com/downloads/).
2. Drag and drop the `.fig` file into the app, or use **File → Import**.

> ⚠️ **Note:** This is a local import. You won't see live updates unless the file owner shares a Figma link directly.

## Viewing tips

- Use **Pages** (left sidebar) to navigate between sections: `Design System`, `Flows`, `Screens`.
- Press `Z` to fit the current frame to screen.
- Press `Ctrl/Cmd + \` to hide the UI and focus on the canvas.
- Click any component and press `Ctrl/Cmd + Alt + C` to inspect styles.
- To view a prototype flow, select a frame and click the **Play** button (▶) in the top-right corner.
